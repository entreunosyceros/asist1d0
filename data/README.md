# Datos locales

Esta carpeta se rellena al **primer arranque** de Asist{1d0}:

- `asist1d0.db` — base SQLite con usuarios, equipos e incidencias **demo**
- `prefs.json` — preferencias locales (p. ej. recordar email)

No se versionan en Git: cada clonación crea su propia base limpia con los ejemplos de demostración.
